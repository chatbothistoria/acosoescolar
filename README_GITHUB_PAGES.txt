PUBLICACION EN GITHUB PAGES

1. Crea un repositorio nuevo en GitHub, por ejemplo: protocolo-acoso-escolar.
2. Sube index.html y .nojekyll a la raiz del repositorio.
3. Entra en Settings > Pages.
4. En Source selecciona Deploy from a branch.
5. Selecciona la rama main y la carpeta /(root), y pulsa Save.
6. GitHub mostrara la direccion publica cuando termine la publicacion.

IMPORTANTE
- No publiques sesiones JSON con datos reales de alumnado.
- La aplicacion carga fuentes, iconos y la biblioteca de PDF desde servicios externos, por lo que esas funciones necesitan conexion a Internet.
- El contenido introducido en el formulario se procesa en el navegador. La funcion Guardar sesion descarga un JSON en el equipo.
